## arXiv-2026-11-19 — Item 1

### A Positive Metric on Four-Dimensional QFTs
**Thomas Hartman, Grégoire Mathys, Andreas Stergiou — arXiv:2611.23370**

Can four-dimensional coarse-graining be ordered by a quantity that decreases at every scale? The endpoint $a$-theorem leaves this stronger question open because the metric in the Jack–Osborn flow equation need not look positive.

Hartman, Mathys, and Stergiou replace the familiar two-point-function construction by a three-point function containing averaged null energy. Resolving it by transverse impact parameter produces a positive spectral density. Integrating that density with a moving cutoff gives a nonperturbative monotonic function interpolating between the endpoint anomalies. In perturbative local renormalization-group language, an explicit counterterm scheme identifies the Jack–Osborn metric with this positive semidefinite density.

**Background.** Averaged null energy integrates the stress tensor along a complete light ray and is a positive operator in the unitary setting considered. Null rotations preserve that ray; their spectral labels supply the impact parameter. This decomposition turns operator positivity into positivity separately at each transverse scale.

**Why it matters?** This supplies a four-dimensional counterpart of the mechanism behind Zamolodchikov monotonicity, connecting energy conditions to geometry in theory space. It establishes monotonicity; a genuine gradient flow remains a separate, unresolved requirement.

## arXiv-2026-11-19 — Item 2

### The limits of magic-state cultivation
**Llorenç Balada Gaggioli, Jakub Mareček — arXiv:2611.24852**

Magic-state cultivation checks an encoded resource state using physical non-Clifford gates and discards runs that fail its checks. Its attractive resource estimates raise a basic question: which combinations of physical faults actually survive postselection and damage the output? Ordinary Pauli propagation cannot answer this directly because a non-Clifford gate turns a Pauli error into a coherent superposition.

The authors convert every non-Clifford gate into resource-state injection, leaving a Clifford circuit acting on ideal resource states. This circuit defines a stabilizer code on the resource-state inputs. A physical fault configuration either triggers a detector or induces a Pauli operator on those inputs; projection onto the resulting code decides whether the accepted output is correct. This places cultivation and distillation within a common exact framework, while retaining their different patterns of fault propagation.

For encoded checks, the framework exposes a problem with replacing physical $T$ gates by $S$ gates in simulations. An $S$ gate converts an $X$ error into a definite $Y$ error, whose extra $Z$ component may be detected. A real $T$ gate instead permits a bare $X$ component to survive. If a parity-measurement circuit spreads one fault over several data qubits, later faults can complete that surviving component into a logical operator. The published distance-three and distance-five cultivation circuits examined here consequently have fault distances two and three. The authors also construct checks using verified cat states that retain the full code distance, with nearest-neighbor examples certified through distance nine.

**Background.** Fault distance counts the smallest number of faulty circuit locations capable of producing an incorrect accepted output. It differs from the distance of the underlying code because an ancilla fault can spread. In a GHZ-fold measurement, a tree of CNOTs collects a logical parity onto one qubit; undoing that tree can spread an error along a branch. A verified cat-state measurement distributes the coupling among separate ancillas and checks their correlations before they contact the data, making dangerous propagation detectable. The paper’s exact test determines whether such protection survives the actual non-Clifford layers.

**Why it matters?** This is a conceptual and practical advance in assessing non-Clifford fault tolerance: it explains why a tractable Clifford proxy can predict the wrong error exponent and provides constructive alternatives. Its certificates concern specified checks and decoder assumptions; a complete cultivation protocol still needs a noisy growth and correction stage that preserves the claimed protection.

## arXiv-2026-11-19 — Item 3

### Fault-tolerant quantum processor with minimal external control
**Christopher A. Pattison, Jeongwan Haah, John Preskill — arXiv:2611.23919**

How little external control does fault-tolerant computation require? Dedicated control lines and off-chip decoding appear to demand an interface that grows with processor size.

The authors construct a planar processor driven almost entirely by a fixed depth-three circuit. Two swap layers transport encoded information past fixed operation regions; a protected classical program steers it through the desired gates. Error correction and instruction decoding occur inside the noisy device. They prove a positive accuracy threshold with nearly linear logical capacity, assuming a noiseless global clock. The fully local design pays a gate latency growing roughly with capacity; ideal instantaneous classical broadcast reduces that latency to polylogarithmic scaling.

**Background.** A logical block circulates on a “tape,” encountering gates laid out spatially in the order an ordinary circuit would apply them temporally. Concatenated error correction implements syndrome processing coherently with ancillas, so centralized measurement feedback is unnecessary. Fresh ancillas remove entropy.

**Why it matters?** This is an existence theorem separating universal fault tolerance from extensive external addressability. It broadens the architecture question toward autonomous local dynamics, although practical thresholds, clock imperfections, and transport overhead still determine engineering value.

## arXiv-2026-11-19 — Item 4

### Stabilizer models of achiral abelian topological orders
**Marvin Qi, Wilbur Shirley — arXiv:2611.24105**

Which topological phases can be represented by exactly solvable stabilizer models? Finite-dimensional stabilizer constructions face strong restrictions associated with the existence of gapped boundaries. Allowing continuous local degrees of freedom changes that question: some phases have zero net chirality yet still lack a gapped boundary, and previous examples suggested that continuous-variable codes could reach them.

Qi and Shirley give a general construction for every achiral two-dimensional Abelian topological order, including fermionic orders. Starting with its signature-zero integer $K$-matrix, they build a lattice of electric-magnetic charges, or dyons, inside a noncompact gauge theory. The dyons to be condensed have trivial mutual braiding. Condensation confines excitations that detect the condensate and identifies surviving excitations that differ by a condensed dyon, reproducing the desired fusion and braiding data.

The microscopic implementation starts from a continuous-variable toric code and gauges a symmetry generated by closed dyon strings. Additional rotor variables describe symmetry defects, while commuting Gauss-law operators move these defects and impose the gauge constraints. Fermionic condensates require physical fermions attached to the corresponding defects. Thus the continuum condensation prescription becomes an explicit stabilizer construction.

**Background.** Achiral here means zero chiral central charge; it does not imply time-reversal symmetry or guarantee a gapped edge. The $K$-matrix records Abelian braiding, and its signature gives the net chirality. The condensation lattice is denoted by $L$; the surviving anyons form $L^\vee/L$, where the dual lattice contains charges braiding trivially with every condensate. A 1-form symmetry acts through closed strings rather than independent transformations on individual sites. Gauging it makes its defects dynamical, which implements the proliferation of condensed dyons. These are the specific bridges from topological field theory to the lattice model.

**Why it matters?** The construction substantially enlarges the known reach of stabilizer descriptions and clarifies that infinite-dimensional local Hilbert spaces alter the boundary between accessible topological orders. The result is presently an ideal construction: exact codewords are non-normalizable, and obtaining normalizable, gapped finite-energy realizations while preserving the order remains a proposed extension. This distinction matters for interpreting it as a route to quantum simulation or error-correcting hardware.

## arXiv-2026-11-19 — Item 5

### A Nonsecular Quantum Master Equation with Detailed Balance and Second-order Error Bound
**Ji-Hui Pei, Jin-Fu Chen — arXiv:2611.24911**

A thermal master equation should preserve positivity, respect microscopic reversibility, and follow relaxation accurately. These demands become difficult to reconcile when transition frequencies are closely spaced. The secular approximation removes interference between different transitions and restores a clean Lindblad structure, but in a dense many-body spectrum it can remove physically important dynamics even at weak coupling.

Pei and Chen construct a completion of the Redfield generator that retains this interference. They first choose the thermal reference using the second-order Hamiltonian of mean force, which incorporates the leading bath-induced correction to the system’s equilibrium state. They then factorize the dissipative coefficients to ensure complete positivity and impose time-reversal Kubo–Martin–Schwinger detailed balance, while matching both dissipative and coherent Redfield coefficients at resonance.

This resonance matching is the key dynamical constraint. In their construction, detailed balance with explicit time reversal permits it, whereas the corresponding condition without time reversal is generically incompatible with it. For a fixed finite-dimensional system, controlled microscopic Redfield errors and sufficiently rapid mixing imply a time-uniform $O(\lambda^2)$ trace-norm error, where $\lambda$ is the system-bath coupling. Exact microscopic calculations for two coupled oscillators test the predicted accuracy across secular and nonsecular regimes.

**Background.** The Hamiltonian of mean force is the effective Hamiltonian whose Gibbs state equals the reduced equilibrium state of the interacting system and bath. It differs from simply adding a dynamical Lamb shift. Using its expansion aligns the master equation’s stationary state with the correct interacting equilibrium. KMS detailed balance expresses thermal reversibility using a Gibbs-weighted relation between forward and reversed operations; including the antiunitary time-reversal transformation changes the permitted coherent terms. Matching at resonance means recovering the Redfield coefficients when two transition frequencies coincide, rather than merely reproducing equilibrium populations.

**Why it matters?** This offers a substantive route toward thermodynamically consistent nonsecular dynamics with controlled accuracy throughout relaxation. Its strongest consequence for many-body physics requires further work: the theorem is for fixed system size, and its mixing and error constants must remain useful as spectra become dense. The oscillator benchmark supports the mechanism without establishing uniform control in the thermodynamic limit.

## arXiv-2026-11-19 — Item 6

### Addressable transversal CCZ gates on almost good quantum LDPC codes and nearly optimal magic state protocols
**Shi Jie Samuel Tan, Guanyu Zhu — arXiv:2611.23762**

A code that stores many logical qubits efficiently is not automatically useful for computation: a transversal gate may act on many logical qubits together, without allowing the desired operations to be selected independently. The challenge is to combine large distance, bounded-weight checks, and a large number of separately selectable non-Clifford gates.

Tan and Zhu construct codes supporting at least $N^{1-\epsilon}$ independently selectable CCZ gates on fixed, disjoint logical triples, with distance $\Omega_\epsilon(N/\log^2N)$ for every fixed $0<\epsilon<1$. A CCZ gate contributes a minus sign only when all three inputs are one. Here any subset of the designated logical gates can be activated through a transversal physical circuit, provided all logical qubits outside the selected logical subspaces are initialized to $|0\rangle$. This is addressability of a predetermined family of triples, rather than arbitrary triples throughout the entire code space.

The construction combines expanding graph covers with a deliberately large shared space of classical codewords. A balanced product reduces the physical size while preserving explicit logical representatives. A trilinear pairing then turns three logical patterns into the phase of a CCZ operation. Choosing a basis whose values distinguish designated evaluation points makes this pairing diagonal on the chosen logical triples, so the associated gates can be selected separately.

The distance theorem assumes uniform subfield product expansion for specified Reed–Solomon codes. The paper treats this as a hypothesis, with its proof deferred to a companion manuscript. Conditional applications include distillation with an arbitrarily small overhead exponent and direct preparation of many encoded CCZ resource states.

**Background.** A balanced product identifies cells related by a common group action, preventing the size increase of an unrestricted Cartesian product. Logical patterns are represented by cocycles, with stabilizers identifying patterns differing by coboundaries. The cup product combines three such patterns into a trilinear quantity; the construction ensures that adding a stabilizer does not change the resulting logical phase. Product expansion controls cancellations among local codewords placed along different coordinate directions: a small resulting support must admit a correspondingly economical decomposition into nonzero lines. This local robustness is what the distance argument needs beyond ordinary graph expansion.

**Why it matters?** The important step is combining substantial logical selectivity with nearly linear distance and bounded checks. It connects the algebra of logical gates to explicit code geometry and multiplicative structure. Its asymptotic implications remain conditional, and efficient decoding, noisy syndrome extraction, and fault-tolerant preparation of the required logical inputs are still needed before the resource advantages become architectural ones.

## arXiv-2026-11-19 — Item 7

### A provably efficient classical algorithm for simulating OTOC$^{(1)}$ in 1D
**Laura Lewis, Antonio A. Mele, Ronald de Wolf, Jarrod R. McClean, Amira Abbas — arXiv:2611.24640**

A scrambling diagnostic can retain a strong dependence on the evolution without being hard to compute classically. Out-of-time-order correlators therefore require a more careful complexity analysis than the observation of chaotic dynamics alone. Even for the ordinary first-order correlator in one-dimensional random circuits, successful numerical approximations had lacked a general efficient-simulation guarantee.

The authors establish such a guarantee through window propagation. They rewrite the correlator as a linear functional of an operator evolving on two copies of the system. Most of this doubled operator can be represented by simple identity and swap regions; detailed circuit-dependent information is retained within a moving window between them. A second truncation limits the spatial diameter of components outside the locally invariant identity-and-swap sector.

Both retained widths need grow only logarithmically with depth and inverse accuracy. The resulting deterministic algorithm has polynomial runtime in system size, depth, and inverse requested mean-squared error, with the error averaged over Haar-random brickwork circuits. It estimates individual circuit correlators, rather than replacing them by their ensemble average. Numerical tests also examine Haar circuits and much larger Clifford circuits containing non-Clifford gates.

**Background.** On two copies, applying the same unitary leaves the identity unchanged and commutes with the swap of the copies. This makes large uniform identity or swap regions cheap to propagate. The window stores deviations from this simple structure, including the information distinguishing one circuit from another. The additional diameter truncation is important to the proof: good performance of a window alone does not establish the stated rigorous guarantee. The method compresses the observable needed for the correlator, rather than the full many-body wavefunction.

**Why it matters?** This gives a precise example in which substantial scrambling information remains classically accessible. It helps identify which correlations might distinguish a quantum simulator from classical methods. The result concerns one-dimensional random-circuit ensembles and first-order correlators; it does not settle the proposed advantage of higher-order correlators in two dimensions or the worst-case complexity of general Hamiltonian dynamics.

## arXiv-2026-11-19 — Item 8

### Free energy distribution for two non-crossing directed polymers on the cylinder
**Andrea De Luca, Pierre Le Doussal — arXiv:2611.23981**

Two directed polymers moving through the same random environment face competing incentives: favorable disorder attracts both toward good paths, while non-crossing prevents them from occupying the same trajectory. How does this constraint change their collective free-energy fluctuations once a finite periodic transverse direction has been explored many times?

De Luca and Le Doussal extend the finite-volume replica approach from one polymer to two mutually avoiding polymers on a cylinder. Disorder-averaged moments of the partition function become an attractive Lieb–Liniger problem, but the relevant ground state lies in the permutation-symmetry sector labeled by the Young diagram $(n,n)$, rather than the fully symmetric sector used for a single polymer. A nested Bethe ansatz introduces auxiliary rapidities to encode this extra structure.

The central technical step is reformulating the coupled Bethe equations into functional and integral relations that admit continuation in the replica number around zero. This yields explicit finite-circumference expressions for the mean and variance of the long-time free energy, together with a systematic expansion for higher cumulants. Taking the large-circumference scaling limit then gives a parametric large-deviation function and analytical asymptotics for both tails. The results are accompanied by perturbative checks and direct polymer simulations.

**Background.** Replication introduces an integer number of copies so that Gaussian disorder averaging becomes an effective attraction among particles. Non-crossing inside each replicated pair imposes a nontrivial exchange-symmetry constraint; the auxiliary part of the nested Bethe ansatz keeps track of that constraint while the physical rapidities determine the energy. The continuation back toward zero replicas extracts cumulants of the logarithm of the partition function. The order of limits matters: the paper takes long polymer length at fixed circumference first, then studies a large cylinder. This is different from the finite-time crossover before the polymer feels the periodic direction.

**Why it matters?** This is a substantial extension of an exact method into a genuinely interacting multilayer fluctuation problem. It supplies detailed predictions for a two-layer periodic Kardar–Parisi–Zhang universality class and a useful benchmark for nonequilibrium fluctuation theory. Universality beyond the continuum model and independent confirmation of the replica continuation remain open; the authors explicitly distinguish those expectations from the formulas derived here.

## arXiv-2026-11-19 — Item 9

### The magical memory cost of entanglement spectrum compression
**Matias Karjula, Vilma Nieminen, Teemu Ojanen, Tapio Ala-Nissila, Moein N. Ivaki — arXiv:2611.24710**

Entanglement entropy measures how much entanglement a state contains, but does not specify how complicated its Schmidt spectrum is. A collection of Bell pairs has extensive entropy and a completely flat spectrum. This suggests asking how much additional quantum memory must remain after local unitaries separate out as many Bell pairs as possible, while allowing the original state to be reconstructed accurately.

The authors solve the fidelity optimization for a single bipartite pure state. The ordered Schmidt probabilities determine the exact tradeoff between extracted Bell pairs and the size of a residual register. Conceptually, the Bell pairs account for repeated flat blocks of the spectrum, while the residual state retains the nonuniform structure that cannot be discarded at the chosen accuracy.

Two bounds clarify what obstructs compression. Smoothed entanglement spread bounds the residual memory from below, and diverging nonlocal magic forces that memory to grow at every fixed positive reconstruction fidelity. In chaotic circuit simulations, the memory cost rises to a size-dependent transient peak and subsequently falls even while entropy continues growing. Typical large Haar-random states eventually need only an accuracy-dependent residual, whereas the stationary fermionic Gaussian states studied retain a cost growing with size.

**Background.** Nonlocal magic here is defined through the best fidelity, after unrestricted local changes of basis, with a state made only of Bell pairs and local pure factors. It isolates an obstruction residing in the entanglement spectrum, rather than magic tied to a particular local basis. Entanglement spread measures spectral nonflatness; smoothing allows small changes consistent with the reconstruction error, avoiding sensitivity to arbitrarily tiny Schmidt weights. A broad hierarchy of significant weights must live in the residual register because tensoring on flat Bell pairs cannot remove that hierarchy.

**Why it matters?** This gives an operational meaning to spectral complexity and separates it sharply from total entropy. It also identifies a transient obstacle relevant to tensor-network compression that entropy alone can miss. The local encoders are unrestricted in complexity, so a small residual is not an efficient preparation or classical-simulation algorithm; the advance is a resource characterization and a diagnostic of nonequilibrium states.

## arXiv-2026-11-19 — Item 10

### Quantum resources and the onset of the quantum Monte Carlo sign problem
**Naga Dileep Varikuti, Leela Ganesh Chandra Lakkaraju, Philipp Hauke — arXiv:2611.23514**

The presence of positive off-diagonal Hamiltonian elements signals a possible Monte Carlo sign problem, but does it locate the regime where simulations actually become unreliable? The authors ask whether the structure of the ground state provides a more informative account of the onset of difficulty.

They tune the signs of local matrix elements in random one-dimensional Hamiltonians and compare tensor-network ground states with projector Monte Carlo calculations at fixed sampling resources. A broad regime remains relatively easy even after the Hamiltonian has become substantially nonstoquastic. The ground-state amplitudes are still nearly positive there, and entanglement and nonstabilizerness remain suppressed. A sharper crossover in these state properties coincides with a steep deterioration of the Monte Carlo estimates.

An approximate construction near the stoquastic limit helps explain the weak-resource regime. Graph states provide a complementary warning against a universal identification of magic with sign difficulty: they have zero nonstabilizerness, yet their signs cannot always be removed by the restricted local Hadamard transformations considered in the paper. Bipartite graphs admit such a removal; non-bipartite graphs do not under that restricted transformation set.

**Background.** Stoquasticity is a statement about Hamiltonian matrix elements in a chosen basis, whereas wavefunction sign complexity concerns the amplitudes of a particular state. The first does not quantitatively determine the second. Projector Monte Carlo evolves a population of samples toward the ground state, and cancellations can become severe when a fixed population cannot represent its signed structure accurately. Consequently, deterioration at fixed walker number is a meaningful algorithmic benchmark, but not a proof of asymptotic computational hardness.

**Why it matters?** The useful contribution is evidence that Hamiltonian signs, state resources, and practical sampling difficulty can separate over a substantial parameter range. It sharpens how one might identify demanding quantum-simulation targets. Extending the observed correspondence to structured physical models, and beyond the chosen basis and Monte Carlo implementation, is the essential next test.

## arXiv-2026-11-19 — Item 11

### Wegner model in high dimension: singular continuous spectrum from U(1) symmetry breaking and AAT self-consistency
**Julian Arenz, Martin R. Zirnbauer — arXiv:2611.24515**

The usual picture of an Anderson transition contrasts localized states with discrete spectral weight against metallic states with a continuous spectral density. A third possibility, a singular continuous local spectral measure, is mathematically allowed but difficult to connect to a physical field-theory mechanism. Arenz and Zirnbauer develop such a mechanism for the high-dimensional Wegner one-orbital model.

Their starting point is that a symmetry-broken field-theory state can be decomposed into extremal states, followed by an integral restoring the symmetry of physical observables. They apply Abou-Chacra–Anderson–Thouless self-consistency to these extremal states separately. Approaching criticality drives the dominant states toward infinity in a noncompact symmetry space. Their residual symmetry approaches a nilpotent subgroup, rather than the compact subgroup characterizing metallic states.

Within this treatment, the critical local spectral measure is singular continuous, and the corresponding energy-projected, disorder-averaged return probability has a $t^{-1/2}$ tail. The proposal is restricted to the critical point of the model studied; the paper does not establish an intervening thermodynamic phase of nonergodic extended states. AAT self-consistency is exact on a tree and is used here as an approximation for local physics at high coordination.

**Background.** A singular continuous measure has neither isolated spectral atoms nor an ordinary density with respect to energy; it can distribute weight on a fractal-like set. The unfamiliar symmetry breaking occurs in the auxiliary field theory, rather than as conventional ordering of electronic spins. Noncompact groups allow symmetry-related states to move arbitrarily far away, so restoring symmetry need not resemble averaging over a compact angular manifold. The nilpotent residual subgroup is shear-like, and changes the critical integration over these states. The physical mixture need not itself break the symmetry broken by its individual components.

**Why it matters?** This is an ambitious field-theoretic explanation of a spectral phenomenon usually approached through localization theory and numerics. It is particularly interesting as a proposed reorganization of strong-disorder criticality. Its significance depends on testing the predicted spectral and dynamical scaling beyond AAT and distinguishing it from competing logarithmically slow critical scenarios; it should be read as a developed mechanism within an approximation, rather than a general theorem about finite-dimensional Anderson transitions.

## arXiv-2026-11-19 — Item 12

### Virtual Autopurification in Translationally Invariant Quantum States
**Atsushi Iwaki, Hideaki Hakoshima, Nobuyuki Yoshioka — arXiv:2611.24448**

Virtual purification estimates observables in $\rho^n/\operatorname{Tr}(\rho^n)$ without physically preparing that state. For a Gibbs state, this increases inverse temperature by a factor of $n$. Its usual implementation, however, requires multiple copies and measurements coupling them. Can one extended homogeneous system supply the copies internally?

The authors use distant translated subregions as approximately independent copies. Each contains the support of the observable plus a surrounding buffer. Entangled measurements cyclically permute the corresponding subregions, producing the same type of numerator and normalization ratio as conventional virtual purification. Translation invariance supplies equal reduced states, while sufficiently weak long-distance correlations make their joint state approximately factorize.

There are two distinct errors: localizing purification to a buffered region, and replacing independent copies by separated regions of one system. The paper analyzes their suppression with buffer size and separation and tests the proposal numerically in a thermal transverse-field Ising chain. The displayed analytical guarantee is more qualified than the abstract alone suggests: it assumes trace-norm clustering and suitable imaginary-time locality, and its separation-dependent estimate is obtained through second order in boundary couplings with a higher-order remainder.

**Background.** The swap identity converts a product of density matrices into a measurement on their copies. Here the same operator is applied to spatial windows, so correlations between those windows become a source of bias. Trace-norm clustering controls the full reduced density operator’s distance from a product, which is stronger than decay of correlations between particular local observables. The buffer addresses a different issue: raising a reduced density matrix to a power need not reproduce the reduced state of the globally powered density matrix. Keeping the observable far from the window boundary suppresses that discrepancy under the stated locality assumptions.

**Why it matters?** This turns spatial repetition into an operational resource for error mitigation and virtual cooling. It can reduce the number of independently prepared systems, especially for homogeneous quantum simulators. It still requires measurements coupling separated windows, and sampling costs grow with the local window and purification order. Establishing stronger nonperturbative bounds would clarify how far the method extends beyond its current controlled regime.

### When Time-Reversible Sensor Records Require Hidden Dissipation
**Andrey V. Dobrynin, Anastasia Stroujkova — arXiv:2611.24898**

Can a time-reversible observation certify hidden dissipation? Reversibility of the visible record removes the usual trajectory-asymmetry witness, but need not make an equilibrium microscopic explanation possible.

The authors analyze a four-state model coupling a hidden binary variable to an observed one. Its complete stationary visible record is reversible, yet switching statistics can exclude every compatible finite-state equilibrium Markov model. They obtain a positive entropy-production lower bound independent of hidden-state number, and an explicit four-state realization supplies an upper bound. At a kinetic matching point these bounds vanish although the actual sensor remains dissipative.

**Background.** Let $g(t)$ be the probability of no visible switch during an interval. For equilibrium Markov dynamics with time-reversal-even variables, persistence is a positive mixture of decaying exponentials. Hence $g(2t)-g(t)^2<0$ is forbidden. The model can violate this constraint while preserving reversal symmetry of complete visible trajectories.

**Why it matters?** The conceptual distinction is between a reversible observed process and one realizable by equilibrium hidden dynamics. It gives nonequilibrium inference information beyond a visible arrow of time. The finite-state Markov and time-reversal-parity assumptions delimit the claim.

### Parisi Energy before Parisi Geometry in the Quantum Approximate Optimization Algorithm
**Maxime Dupont, Bhuvanesh Sundar — arXiv:2611.23645**

Reaching a good spin-glass energy and reproducing the organization of low-energy configurations are different achievements. Classical equilibrium sampling encounters a hierarchy of competing valleys. Does a quantum optimization circuit develop that same geometry as its energy improves, or can it approach the optimum through a different distribution of configurations?

Dupont and Sundar study the output of the quantum approximate optimization algorithm for the Sherrington–Kirkpatrick model directly in the thermodynamic limit. They draw two configurations from the same disorder instance and bias them toward a common overlap, $q=N^{-1}\sum_j z_j^{(A)}z_j^{(B)}$, where the two sets of Ising spins label the samples and $N$ is system size. The resulting overlap potential measures the cost of forcing two outputs to resemble one another.

At the finite depths studied, typical outputs remain macroscopically uncorrelated, even as their overlap susceptibility grows. Reweighting toward the low-energy tail reveals an instability toward glassy organization. At depth one, the authors characterize the emerging phase and recover Parisi structure with the thermal transition’s critical behavior; the corresponding interpretation at higher depths is anticipated from the instabilities. As circuit depth increases, this organized tail becomes energetically closer to typical outputs and less statistically rare.

**Background.** The overlap source is a diagnostic of the output distribution, not an extra gate in the algorithm. An energy tilt similarly reweights existing samples to inspect their rare tail without claiming that the circuit produces those samples typically. A Franz–Parisi-type potential converts the overlap-generating function into a cost for a specified overlap. Its curvature near zero gives the inverse susceptibility. The auxiliary replicas used to average the logarithm over disorder are mathematically separate from the two physical samples whose resemblance is being tested.

**Why it matters?** This gives a statistical-mechanical account of algorithmic progress beyond average energy and suggests that good energies can precede typical equilibrium-like glass geometry. It is a worthwhile bridge between quantum algorithms and nonequilibrium distributions. The evidence does not establish quantum advantage: classical algorithms already exploit the special structure of this model, and conclusions about infinite depth remain extrapolations from finite-depth analysis.

## arXiv-2026-11-19 — Item 16

### Look Mum, No Hands! Quantum State Preparation without Time-Dependent Control
**Tomasz Andrzejewski, Yuri Minoguchi, Phila Rembold, Konrad Szymański — arXiv:2611.23382**

If Hamiltonian couplings can be chosen once but cannot change during evolution, how much state preparation remains possible? Time-dependent control exploits commutators generated by switching interactions; its familiar Lie-algebra criterion therefore does not directly answer the autonomous problem.

The authors instead separate eigenstate populations from phases. Evolution under a fixed Hamiltonian preserves populations in its energy basis and changes only relative phases. Static couplings must make the initial and target population distributions agree. For rationally independent energy gaps, sufficiently long evolution can then approximate the desired relative phases arbitrarily well.

This viewpoint yields a cheap unreachability certificate from the first two energy moments. Equal mean energies restrict the allowed coupling vectors to a hyperplane. If the difference of the second-moment quadratic forms is strictly definite on that hyperplane, no nonzero coupling choice can match both distributions. A more demanding numerical criterion compares the full energy populations.

**Background.** The closure is essential: a one-parameter orbit can wind densely around a torus of relative phases, even though its instantaneous trajectory is only a curve. Thus parameter counting based solely on evolution time misses approximate recurrence. Population matching identifies the torus containing the target, while irrational energy-gap ratios allow its phases to be approached. This is a geometric reachability statement, not a constructive bound on a short preparation time; the paper finds very unfavorable waiting-time growth for phase alignment.

**Why it matters?** The work gives useful obstructions and a clear separation between expressivity, accuracy, and preparation time. It broadens the theory of static quantum simulation and control without assuming that an expressive Hamiltonian family is an efficient state-preparation algorithm. The distinction between generic exact reachability and high-fidelity finite-size coverage is particularly valuable when evaluating autonomous variational proposals.

### Computing $F$-Symbols from Modular Data
**Jonah Berean-Dutcher, Clay Cordova, Julio Parra-Martinez, Richard Tuddenham — arXiv:2611.24753**

Knowing anyon fusion rules and modular matrices does not automatically provide a complete topological theory. One still needs consistent changes of basis between different fusion orders. Solving all of their nonlinear consistency equations directly becomes difficult when many anyon types or multiple fusion channels are present.

The authors reconstruct these $F$-symbols by climbing a ladder of braid-group representations. They assume a self-dual simple generator: an anyon equal to its antiparticle whose repeated fusion produces every anyon type. Adding another strand inherits the braid action already known on fewer strands, leaving a more limited new problem. Hexagon relations, braid relations, and selected pentagons enlarge the solved family until mostly linear equations propagate it to the remaining symbols.

The search is numerical and does not guarantee finding every solution. Once a candidate is obtained, reconstruction in a specified number field allows exact certification of every pentagon and hexagon equation. The method handles fusion multiplicities and difficult rank-eleven and rank-twelve examples, including a rank-eleven category with millions of symbols reconstructed in roughly ten minutes on a laptop.

**Background.** An $F$-matrix relates the basis in which the first two of three anyons fuse first to the basis in which the last two fuse first. Multiplicity means that even a fixed input and output charge can admit several independent fusion junctions. The modular $S$ and $T$ matrices encode mutual braiding and topological spins, but inequivalent categories can share them. Pentagon equations enforce consistency among successive regroupings; hexagon equations enforce compatibility between regrouping and exchange. The braid ladder exploits already determined exchange actions to constrain new regroupings, reducing the nonlinear problem rather than assuming modular data uniquely fix its answer.

**Why it matters?** This makes abstract candidate topological data usable for constructing theories and calculating braiding operations. It is a substantive computational method with exact final certificates, relevant to topological quantum computation and solvable lattice constructions. Its scope is defined by the generator and number-field assumptions, and successful certification should be distinguished from completeness of the numerical search.

### Odd-Even Effects on Liouvillian Spectra and Relaxation Dynamics in Boundary-Driven Spin Chains
**Zhen-Yu Zheng, Shu Chen — arXiv:2611.24053**

Can adding one spin determine whether boundary dissipation destroys coherent dynamics altogether? In the models studied here, chain parity changes which bulk degrees of freedom the same endpoint noise can reach. The effect is therefore stronger than a smooth finite-size correction to a relaxation rate.

The authors examine a zero-field XY chain with spin-flip jump operators at both ends, together with related cluster chains. A Majorana representation splits the XY Hamiltonian into two independent paths of coupled operators. For even chain length, both dissipative contacts act on the same path in the even operator sector, leaving the other isolated. For odd length, the contacts reach both paths. The isolated path generates a non-decaying sector and, when appropriate frequencies and overlaps are present, persistent oscillations.

The corresponding parity preference reverses in the cluster-chain example. Analytical spectral results and covariance-matrix evolution connect the undamped modes to bond correlations or magnetization after simple product-state preparation. Their existence and frequencies do not depend on the magnitudes of the positive boundary rates, although they do depend on the specified Hamiltonian and boundary channels.

**Background.** A Majorana path is a sequence linked by the quadratic Hamiltonian, rather than an additional spatial wire. On a path contacted at an endpoint, an undamped eigenmode would have to vanish at that endpoint; the nearest-neighbor eigenvalue equations then force it to vanish along the entire path. An uncontacted path avoids this obstruction. Even products of its Majorana operators supply physical operators protected from dissipation. Purely imaginary Liouvillian eigenvalues describe persistent frequencies, but an observable oscillates only if its preparation and measurement overlap with those modes.

**Why it matters?** This is a transparent exactly solvable mechanism for preserving an operator sector inside an open many-body system. It provides a useful warning against assuming smooth size scaling and a concrete setting for exploring dissipation-free information. The protection follows from special connectivity and boundary coupling, so robustness to generic bulk perturbations is a separate question.

### High-rate low-distance color codes
**Peter-Jan H. S. Derks, Lucas Berent, Mark Webster, Robert Wille, Jens Eisert, Aleksander Kubica — arXiv:2611.23420**

Small error-corrected devices need to protect several logical qubits efficiently before large-distance asymptotics become decisive. Familiar triangular color-code patches encode only one logical qubit, motivating a search for compact alternatives that use their boundary and topology more efficiently.

The authors construct distance-three color codes with encoding rate $1/3$ and distance-four codes with rate $1/4$. They prove these rates optimal within the stated class: color codes with only color boundaries on surfaces of non-negative Euler characteristic. The restriction matters; it does not cover arbitrary mixtures of boundary types or surfaces of higher genus.

They then design Steane-style error correction for a linear trapped-ion chain model with all-to-all connectivity and serial unitary gates. Encoded ancillas are verified using real-time feedback, and failed preparations are restarted while accounting for errors accumulated by waiting data. The $[[20,4,4]]$ and $[[16,4,4]]$ examples perform best in their benchmarks, reaching break-even at two-qubit gate infidelities of $0.22\%$ and $0.26\%$, respectively. These are model-dependent circuit results, rather than hardware demonstrations or asymptotic thresholds.

**Background.** Color boundaries arise by cutting the colored lattice so that selected anyon strings can terminate; changing boundaries, corners, and periodic identifications changes the number of independent logical strings. The construction balances those logical degrees of freedom against the shortest undetectable operators. Steane-style extraction uses an encoded ancilla and transversal CNOTs to obtain all checks of one Pauli type together. Its cost therefore depends strongly on reliable encoded-state preparation, and the rate of the data code alone does not count all syndrome-extraction qubits.

**Why it matters?** This combines a restricted optimality theorem with concrete circuit benchmarks, making it more informative than a catalog of small codes. It offers credible multi-logical-qubit memory candidates for modest devices and illustrates why code rate must be assessed together with extraction circuitry and connectivity. It is a practical contribution within low-distance error correction, with broader performance requiring a different scale of codes and circuits.
