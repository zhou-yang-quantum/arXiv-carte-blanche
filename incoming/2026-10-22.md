## arXiv-2026-10-22 — Item 1

### Local Clifford equivalence to CSS codes: Polynomial-time classification and conversion
**Mingyuan Wang, Stefan Krastanov — arXiv:2610.28737**

A stabilizer code can look non-CSS simply because its physical qubits use inconvenient Pauli axes. Recognizing this hidden structure matters: it determines whether familiar CSS decoding and logical-gate constructions can be transferred to the code. Checking one proposed basis is straightforward, but searching independently over local Clifford choices appears exponentially expensive, especially because changing stabilizer generators can conceal pure checks.

Wang and Krastanov give a deterministic classification and conversion algorithm using $O(mn^2+n^4)$ binary field operations, where $m$ counts supplied generator rows and $n$ counts physical qubits. Its central move is to search for local projectors preserving the stabilizer label space. After decomposing independent components, apparently quadratic projector constraints reduce to two affine linear systems per component. Acceptance produces the local Clifford transformation and CSS checks; rejection rules out every such transformation.

The conversion preserves code parameters and bounded check sparsity. Decoder transfer also requires transforming the noise probabilities: a useful CSS representation does not automatically turn the physical noise into independent bit and phase errors.

**Background.** Binary Pauli labels represent each qubit’s X and Z components by two bits. The relevant rank-one projector acts on these classical labels, rather than measuring the quantum state. In CSS coordinates, keeping only the X component of any stabilizer must produce another stabilizer; the complementary projection supplies its Z component. The algorithm searches for a rotated version of this splitting. This explains why it must examine the whole stabilizer span, rather than classify the supplied checks individually.

**Why it matters?** This supplies a practical test of whether an apparently new non-CSS construction possesses genuinely different local Clifford structure. A positive answer opens access to existing computational tools; a negative answer makes the distinction precise. For QEC and its statistical-mechanics connections, that separation is valuable: changing representation, changing noise bias, and changing the underlying code are different operations whose consequences should be assessed separately.

## arXiv-2026-10-22 — Item 2

### Injection is all you need: parallel universal logic in high-rate concatenated self-dual codes
**Joseph Sullivan, David Amaro, Michael A. Perlin — arXiv:2610.30087**

Encoding many logical qubits in one block saves memory, but computation benefits only if selected logical qubits can be operated on concurrently. Global transversal gates often leave an addressability bottleneck: the code stores many qubits while forcing otherwise independent operations to be serialized.

The authors move addressability into prepared resource states. For concatenations of suitable self-dual CSS seed codes, global logical Hadamard and phase gates, together with arbitrary logical CSS resource states, suffice to inject every Clifford circuit. Nine resources suffice for a Clifford stage. Global magic states $|H\rangle^{\otimes K}$ complete universality, giving a resource count bounded by $12D_T$ for an algorithm of T-depth $D_T$. Here the single-qubit H state is the positive Hadamard eigenstate.

Steane and Knill teleportation gadgets consume these resources while extracting error syndromes. Preparation combines flag-at-origin verification of CSS states with concatenated cultivation of magic states. The numerical evidence uses Clifford proxy circuits under a specified depolarizing model, rather than direct simulations of the full magic-state circuits. Reported resource-state comparisons show substantial spacetime savings, but complete algorithm costs remain unbenchmarked.

**Background.** Gate teleportation places an operation into an ancilla state and transfers it to unknown data through entangling gates, measurements, and outcome-dependent corrections. The difficult circuit can therefore be prepared before the data arrives.

Flag-at-origin exploits CSS preparation circuits whose CNOTs run between two sets of qubits. Flags intercept faults near the points from which they could spread. Concatenated cultivation instead checks global Hadamard parity at successive encoding levels. A correlated error missed within one small block can become detectable by checks crossing blocks at the next level. The resulting suppression must still survive decoding when the resource is consumed.

**Why it matters?** The conceptual contribution is a route from high encoding rate to high computational bandwidth: selective operations are specified by resources rather than by a separate addressable gate mechanism for every code. The decisive next comparison is a complete computation, including resource supply, feedforward, and online rejection. Those costs determine whether the attractive preparation benchmarks translate into an advantage for fault-tolerant algorithms.

## arXiv-2026-10-22 — Item 3

### Quantum Simulation of Non-Markovian Open Quantum Systems via Low-Rank Kernel Compression and Coupling Dilution
**Hengzhun Chen, Zhenning Cai — arXiv:2610.29372**

Simulating an environment with memory seems to require keeping an enormous collection of bath degrees of freedom. Yet the system may respond to only a small fraction of their collective temporal structure. The useful question is therefore how much environmental information must be retained to reproduce the reduced dynamics, with an explicit error guarantee.

For an initially uncorrelated system and Gaussian bath, with linear coupling and zero bath mean, the complete influence is fixed by the two-time correlation kernel $G(t,s)$. Chen and Cai diagonalize this kernel on the finite simulation interval and retain its dominant temporal profiles. Schematically, the compressed kernel is

$G(t,s)\simeq\sum_{n=1}^{N}g_n(t)g_n^*(s)$.

Each retained profile becomes a time-dependent coupling to an auxiliary oscillator initially in vacuum. The number $N$ measures the effective temporal rank, rather than the microscopic number of bath oscillators. Thermal fluctuations can be represented too: their information enters the coupling functions, so the auxiliary bath need not itself be initialized thermally.

The remaining obstacle is oscillator occupation. Strong accumulated coupling can populate many levels, making a small qubit encoding inaccurate. Coupling dilution replaces one oscillator by several independent copies with weaker couplings, chosen so that their correlations add to the original kernel. Before truncation this replacement is exact. After truncation, it trades more registers for fewer levels per register.

The paper bounds errors from kernel compression, occupation truncation, and digital evolution separately. Polynomial circuit resources follow under quantitative assumptions on kernel spectral decay, coupling smoothness, and efficient implementation of the elementary unitaries. This is a conditional complexity result; it does not establish efficient simulation for every environment or remove the cost of the system Hamiltonian.

**Background.** The effective modes are temporal correlation patterns, not necessarily physical normal modes at particular frequencies. A bath containing many microscopic oscillators can have a simple finite-interval kernel, while a smaller bath can generate complicated temporal structure.

An important subtlety appears after occupation truncation. The truncated modes retain the same vacuum two-point correlation but cease to be Gaussian. Their higher moments can therefore change the dynamics, so matching the kernel alone no longer proves equivalence. The separate occupation-error analysis closes precisely this gap. Dilution helps because each copy is less likely to reach the omitted levels, while the full collection retains the required fluctuation strength.

**Why it matters?** This offers a controlled way to organize quantum simulation around environmental memory rather than environmental size. Its strongest potential lies in baths with rapidly decaying kernel spectra, including nonstationary situations poorly described by a single fixed memory window. For non-equilibrium physics, the framework makes the approximation budget unusually transparent. Representative numerical kernels and complete circuit implementations are needed to determine when that transparency also yields a practical resource advantage.

## arXiv-2026-10-22 — Item 4

### Hydrodynamic description of correlation matrix eigenvalues in a finite temperature expanding free fermionic gas
**Atharva Naik, Madhumita Saha, David A. Huse, Manas Kulkarni, Abhishek Dhar — arXiv:2610.30062**

Hydrodynamics can reproduce particle flow while missing the quantum coherence needed to compute entropy. A particularly sharp example is a finite Fermi gas escaping through a defect into an empty reservoir. Earlier hydrodynamic calculations reproduced the system’s entropy rise and fall, but applying the same local entropy prescription to the reservoir incorrectly produced continuing growth.

The authors resolve this mismatch using a semiclassical description of the correlation matrix eigenvalues. They consider a thermal free-fermion gas initially confined to a finite one-dimensional box, coupled to a semi-infinite empty chain through a point defect. An initially localized wavepacket partly escapes at each encounter with the junction. The reflected part returns after bouncing from the wall, producing a train of transmitted packets in the reservoir.

Those transmitted pieces share one coherent origin. Counting each spatially separated piece as an independent statistical contribution artificially increases entropy. The proposed reservoir prescription instead combines the pieces belonging to the same original wavepacket before applying the entropy functional. Operationally, it sums phase-space densities across successive reservoir cells whose lengths equal twice the initial box length. For the system, the ordinary phase-space occupation already supplies the required eigenvalue description.

The resulting spectra reproduce microscopic numerical calculations closely and yield both von Neumann entropy and full counting statistics, including transient number fluctuations beyond the usual steady-transport setting. The derivation is heuristic and semiclassical. A small set of eigenvalues missed by it produces subleading corrections, including logarithmic entropy terms. At finite initial temperature, the subsystem entropies also contain thermal mixedness and should not be interpreted as pure-state entanglement entropies.

**Background.** Yang–Yang entropy applies the fermionic occupation entropy to a distribution in phase space. Its success requires those occupations to represent the independent modes relevant to the reduced state. Position-space density alone does not establish that independence.

Here an overlap matrix built from the evolved initial wavepackets has the same nonzero spectrum as the restricted correlation matrix. In the semiclassical picture, distinct initial packets remain approximately independent, but the many emitted peaks of one packet remain coherent. This gives the conceptual bridge between hydrodynamics and the spectrum: the reservoir must be organized by coherent packet ancestry, rather than by the present locations of its peaks.

**Why it matters?** The advance is an explicit mechanism for repairing an information-theoretic observable when ordinary hydrodynamic density data are insufficient. It provides a useful solvable example of how apparent entropy production can arise from discarding coherence during coarse graining. The connection to non-equilibrium entanglement is substantive, while extension to interacting systems would require identifying what replaces the independent wavepacket structure.

## arXiv-2026-10-22 — Item 5

### Generalized Coordinate Bethe Ansatz and Quantum Integrability of the Time-Dependent Massive Thirring Model
**Parameshwar R. Pasnoori — arXiv:2610.29998**

An exactly known instantaneous spectrum does not solve a driven quantum field theory: its eigenstates themselves change in time. The challenge is to retain a many-body construction that satisfies the actual evolution equation, including interactions and periodic boundary conditions.

Pasnoori constructs a generalized coordinate Bethe ansatz for a constant four-fermion interaction and an exponentially varying bare mass,

$m_{\mathrm{b}}(t)=m_{*}e^{\kappa t}$.

Here $m_{*}$ sets the mass scale and $\kappa$ is the ramp rate. Compatibility selects this protocol within the chosen rapidity-factorized family. Spatial winding shifts a one-particle rapidity, $\beta\to\beta-p$, with $p=\kappa L$ for circumference $L$. Periodicity therefore requires a rapidity lattice, rather than a single fixed-rapidity block. Interactions determine its relative amplitudes through scalar analytic difference equations.

The result is a formal exact finite-particle wavefunction. Selecting normalizable physical states, prescribing convergence of the lattice sum, and extracting evolution from a chosen initial many-body state remain open. The empty reference state used in the construction is also distinct from the filled physical vacuum.

**Background.** In the coordinate Bethe ansatz, one solves the wavefunction separately in regions with different particle orderings, then relates neighboring regions by two-particle scattering. On a circle, taking a particle around the system provides an additional consistency condition.

The novelty here is that winding changes the spectral label itself. The scattering problem consequently fixes weights between neighboring rapidities through finite-shift equations. This is the role of the analytic difference equations: they replace ordinary algebraic quantization conditions within the driven construction. The exponential restriction concerns this compatible ansatz, rather than a general impossibility of solving other mass protocols.

**Why it matters?** This is a promising structural advance toward exact real-time interacting QFT, with a concrete connection between driving protocols, periodic transport, and integrability. Its present significance is the construction of the solution machinery. Physical vacuum dynamics and correlation functions would make the next decisive step. The relation to sine-Gordon theory also offers a useful setting for comparing quantum wavefunction methods with classical time-dependent integrability.

## arXiv-2026-10-22 — Item 6

### Orientifold and Integrability: $\mathcal{N}=4$ Super-Yang-Mills on $\mathbb{RP}^4$
**Joao Caetano, Shota Komatsu, Paolo Soresina, Anders Wallberg — arXiv:2610.28725**

Putting an integrable field theory on a non-orientable spacetime need not preserve the structures that make it solvable. The question becomes especially interesting when the identification has a holographic interpretation: can observables associated with an orientifold be studied using exact gauge-theory tools?

The authors place supersymmetric Yang–Mills theory on real projective four-space, combining the spacetime identification with an R-symmetry action and gauge-group charge conjugation. Charge conjugation is crucial to their integrable construction. At leading weak coupling, the relevant Wick contractions pair fields at opposite positions inside a single trace. Through the operator–spin-chain correspondence, one-point functions become overlaps of Bethe eigenstates with a spin-chain crosscap state.

They calculate these overlaps in several bosonic and supersymmetric subsectors. The results exhibit the root-pairing selection rules expected of integrable states and admit determinant expressions. A formula for the full superconformal sector is conjectured from these results and consistency requirements; general unprotected finite-coupling overlaps are not established.

A complementary supersymmetric localization calculation treats protected half-BPS one-point functions at finite rank and coupling. It reduces the problem to charge-conjugation-twisted two-dimensional Yang–Mills theory on the real projective plane, with the required zero-instanton projection, and then to a matrix integral. Its planar solution interpolates between weak-coupling calculations and the proposed probe-orientifold description at strong coupling. Worldsheet calculations in the pp-wave limit provide additional evidence for that dual interpretation.

**Background.** A crosscap implements a non-orientable identification: one may picture removing a disk and identifying antipodal points on its boundary. In the simplest spin-chain sector here, the corresponding state entangles spins separated by half the chain length. This pairing follows from the gauge-theory contractions, giving a physical reason for the overlap construction.

The state is annihilated by odd conserved charges. Its overlap therefore vanishes unless the Bethe roots have the appropriate opposite-root pairing. Gaudin determinants are Jacobians of the Bethe quantization equations; after separating fluctuations compatible with the pairing, their ratio controls the normalized overlap. Localization addresses a different protected set of observables and supplies an independent coupling-dependent check.

**Why it matters?** This extends exact-observable methods into a non-orientable setting where the identification itself might have destroyed integrability. The strongest feature is the agreement between spin-chain calculations, protected finite-coupling results, and holographic limits. For interests in exact QFT and integrable models, it opens a new class of observables beyond spectra and conventional boundaries. Establishing general finite-coupling crosscap overlaps remains the central next development.

## arXiv-2026-10-22 — Item 7

### Finite Classification of Transversal Diagonal Gates Beyond Stabilizer Codes
**Xi He, Chao Zhang, Shilin Huang, Bei Zeng — arXiv:2610.29955**

Leaving the stabilizer framework can enlarge the possibilities for transversal logical gates, but it also removes much of the algebra that makes code searches manageable. Even for a small block, continuously varying physical phase gates appear to leave an unbounded search problem. Knowing that the logical symmetry group is finite does not by itself bound the orders of physical gates needed to represent it.

The authors close this gap for diagonal transversal gates on exact qubit codes of distance at least two. Every projective logical action has a finite-order physical representative whose order is bounded using only code parameters. Continuous families of code-preserving physical phases can still exist, but the continuous directions act only as a common phase on the code. Logical phase sectors have matching local moments, allowing their phases to be replaced by rational solutions with bounded denominators.

This makes subset-sum linear programming an exhaustive finite outer search, followed by exact error-correction constraints on amplitudes. For the nontrivial diagonal sector of $((6,2,3))$ codes, physical representatives of order at most nine suffice. The search yields 66 candidate symmetry classes, of which 15 admit exact completions. Possible nontrivial projective diagonal logical group orders are two, three, and five.

These are symmetry-data classes, not fifteen inequivalent codes. The order-five sector does have a stronger result: it contains one code up to local unitaries and qubit permutations, equivalent to a previously constructed code. Six physical qubits are also minimal for its order-five distance-three logical action. Much of the finer code-level classification in the other sectors remains open.

**Background.** The notation here specifies six physical qubits, a two-dimensional code space, and distance three. It does not use the stabilizer convention in which the middle entry counts logical qubits.

A diagonal product gate assigns a computational-basis string a phase determined by a weighted sum of its bits. Logical eigenvectors must occupy strings in particular phase classes. Equal expectations of local Z errors become matching first moments of those strings; distance three also imposes matching second moments. Linear programming tests whether nonnegative probability weights can satisfy these conditions. It cannot determine all relative quantum phases, so the remaining Knill–Laflamme equations are essential for proving that a candidate is an actual code. A projective logical action ignores its physically irrelevant overall phase; its order can differ from the order of a physical representative.

**Why it matters?** The main advance is the passage from construction by search to a search that can certify completeness without assuming stabilizer structure. This gives a systematic route to understanding which fault-tolerant gate resources small non-stabilizer codes can possess. It is a classification result rather than a scalable computing architecture, but it establishes unusually sharp boundaries around the possibilities that architecture proposals may exploit.

## arXiv-2026-10-22 — Item 8

### Stable and causal frames for BDNK hydrodynamics
**Jay Armas — arXiv:2610.28984**

A relativistic hydrodynamic theory can reproduce the correct long-wavelength transport coefficients while its truncated equations develop acausal propagation or unstable short-wavelength modes. That becomes a practical obstacle when the equations are evolved numerically: unwanted modes can spoil access to the hydrodynamic observables themselves.

The Bemfica–Disconzi–Noronha–Kovtun formulation uses freedom in defining hydrodynamic variables to make first-order constitutive relations yield stable, causal evolution. The difficulty is choosing the additional coefficients for a specified fluid. General inequalities exist, but solving them afresh for each equation of state and each set of viscosities and conductivity is cumbersome.

Armas constructs six explicit families of frames for neutral and charged fluids, three with finite conformal limits. The equation of state and physical transport remain prescribed inputs, subject to the paper’s regularity, thermodynamic stability, and subluminal sound assumptions. Free frame parameters then adjust characteristic speeds.

The simplifying mechanism is polynomial factorization. The charged longitudinal dispersion relation is normally sixth order. Suitable coefficients factor it into a neutral-type quartic and a quadratic of telegrapher form. The latter describes a diffusive mode accompanied by a damped relaxation mode, with a finite characteristic speed. Reduced Routh–Hurwitz criteria make the remaining stability conditions tractable. The paper checks stability and characteristic speeds at arbitrary uniform boosts, rather than relying exclusively on rest-frame dispersion relations.

These are principally linear stability and causality results. Existing nonlinear theorems apply to specified subfamilies under additional hypotheses; well-posedness for the full constructed families remains a further question.

**Background.** Hydrodynamic frame freedom means redefining temperature, chemical potential, and velocity by derivative corrections while leaving the physical stress tensor and current unchanged to the retained order. It is distinct from changing the inertial observer. Once truncated equations are treated as a complete evolution system, these choices affect additional nonhydrodynamic modes.

The telegrapher equation adds a second time derivative to diffusion. At long wavelengths it retains diffusion, while at short wavelengths the extra relaxation scale permits finite propagation speed. Here that structure is engineered inside the conservation equations without introducing the dissipative stresses as independent variables. Routh–Hurwitz criteria convert the requirement that all modes decay into algebraic inequalities on polynomial coefficients, making the factorization useful for constructing actual frames.

**Why it matters?** This turns broad consistency conditions into usable coefficient prescriptions across a substantial class of relativistic fluids. Its relevance extends beyond a particular application: it shows how the nonhydrodynamic completion of a dissipative effective theory can be adjusted while measured transport remains fixed. Numerical comparisons and broader nonlinear well-posedness results will determine which families provide the most reliable tools for non-equilibrium evolution.

## arXiv-2026-10-22 — Item 9

### The Standard Model on a finite bosonic lattice with continuum Weyl fermions
**Stephen D. H. Hsu — arXiv:2610.29019**

Regulating a chiral gauge theory requires preserving both exact gauge consistency and the physical effects of fermion topology. The Standard Model cancels its gauge anomalies, while retaining anomalous global-current selection rules and fermion zero modes. A regulator must handle this distinction throughout its construction.

Hsu develops a hybrid formulation in which gauge and Higgs variables occupy a finite lattice while Weyl fermions remain continuum fields. Smooth gauge-covariant reconstruction turns admissible lattice configurations into continuum backgrounds, including nontrivial bundles. The fermions contribute a renormalized complex determinant whose phase is made consistent using Standard Model anomaly cancellation.

The main additional construction incorporates Yukawa couplings. Gauge-covariant spectral filters suppress high-energy contributions at the Yukawa vertices while leaving the massless continuum kinetic operator intact. Fermion-loop power counting gives $\omega=4-n_Y$, where $n_Y$ counts Yukawa insertions. Only the low-order local ultraviolet terms require subtraction; finite momentum-dependent contributions remain. Mixed gauge–Yukawa effects enter through the background-dependent propagators and filters, so they are included in the prescription.

Under the stated smooth-family assumptions and compact bosonic cutoffs, the fermion spectral cutoff can be removed while retaining a finite, exactly gauge-invariant bosonic integral at fixed lattice spacing and volume. Zero modes are handled through source insertions and determinant minors, allowing physical amplitudes even where the vacuum determinant vanishes.

The independent bosonic continuum limit remains open. Reflection positivity is proved for a variant reconstruction at zero Yukawa coupling and vanishing theta angle, rather than for the general interacting prescription. Locality properties in the original lattice variables also require further work.

**Background.** A chiral determinant has a phase-consistency problem because its operator maps between different chiral spaces. As the gauge background changes, the determinant naturally belongs to a background-dependent one-dimensional complex space, called a determinant line. Choosing these phases consistently resembles transporting quantum-state phases with a Berry connection. Local and global gauge anomalies are obstructions to making that transport gauge invariant.

This language is especially useful at zero-mode crossings, where dividing one determinant by another can fail. The construction instead retains finite-dimensional zero-mode factors explicitly and matches the nonzero-mode contribution across overlapping descriptions. Admissibility and bounded Higgs support ensure that the reconstructed backgrounds remain within a controlled smooth family; they are substantive assumptions behind the finiteness theorem.

**Why it matters?** This is a concrete finite-regulator construction that keeps continuum chirality, anomalies, and Yukawa interactions together. Its contribution is to define the fermionic weight consistently before addressing removal of the bosonic regulator. For QFT, that provides a useful alternative organization of the chiral-regulation problem. Establishing the continuum limit, appropriate locality, and positivity for the interacting theory would be necessary before claiming a complete nonperturbative Standard Model definition.

## arXiv-2026-10-22 — Item 10

### Interacting quantum reference frames
**Leonardo Chataignier, Alexander R. H. Smith — arXiv:2610.28732**

A physical clock or spatial reference frame can interact with the system it describes. This is unavoidable in gravitational settings, yet extending quantum reference-frame methods to interacting systems has produced apparent failures of unitary conditional evolution. The question is whether those failures represent physical information loss or an incorrectly normalized relational description.

Chataignier and Smith formulate the problem through constraint quantization. Group averaging constructs gauge-invariant physical states from a larger kinematical Hilbert space. Choosing a frame orientation then acts as a gauge fixing. Crucially, the gauge-group action need not factor into separate actions on the frame and system, so the framework can accommodate interactions.

The key construction is a positive, operator-valued Faddeev–Popov factor. It is obtained by inverting the gauge average of the chosen orientation’s measurement effect. Inserting its square root before conditioning makes the conditional-state overlap equal to the physical overlap. Reduction to a frame therefore preserves the physical inner product, and composing one reduction with another’s inverse gives a unitary change-of-frame map between the corresponding conditional Hilbert spaces.

Temporal examples produce unitary relational evolution for interacting clocks and recover previously studied time-nonlocal equations in appropriate limits. Spatial examples show that interactions modify how coherence in one frame corresponds to entanglement in another.

The theorem assumes a unimodular gauge group, for which left and right invariant integration measures agree, and a well-defined invertible gauge-averaged orientation effect. If the latter has a kernel, the construction may apply only on a suitable subspace. The authors identify this as a potential analogue of the obstruction to global gauge fixing.

**Background.** Page–Wootters conditioning describes a system at a clock reading by projecting a globally constrained state onto that reading. With interactions, the naive projected state need not carry the physical normalization inherited from the constraint.

The Faddeev–Popov factor corrects the operator-valued weight with which a chosen frame orientation samples the gauge orbit. It consequently changes both conditional states and the relational observables used to assign probabilities; it is more than a scalar renormalization applied after evolution. The result concerns fully conditioned descriptions. Ordinary reduced-state dynamics obtained by ignoring a clock or environment can still be nonunitary.

**Why it matters?** This gives a precise criterion for distinguishing an apparent loss of unitarity caused by relational normalization from physical open-system decoherence. The contribution connects familiar gauge-fixing logic to quantum clocks and subsystem descriptions, making it a worthwhile broader direction for QFT and quantum information. Extending the construction through noninvertible frame effects, and testing its relation to other formulations of relational observables, are the important unresolved steps.
